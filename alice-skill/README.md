# Навык Алисы «Хоуми» — сообщения с колонки на компьютер

«Алиса, попроси Хоуми передать: ужин готов» → компьютер с Homie говорит «Тебе передали: ужин готов».

Каждый пользователь создаёт **свой приватный навык** — он виден только ему, общих серверов нет.
Код программы трогать не нужно: код навыка и ключ копируются кнопками в настройках Homie.

## Как это устроено

```
Колонка → навык «Хоуми» → функция в Yandex Cloud ──(подпись ключом)──► канал ntfy.sh ──► Homie на ПК
```

Компьютер сидит за роутером, поэтому Homie сам подключается к каналу и ждёт сообщений.
Канал и подпись выводятся из «Ключа связи»: чужие сообщения Homie отбрасывает.

## Настройка (один раз, минут 10)

Всё нужное — в Homie: **Настройки → «Сообщения от Алисы»** (раздел свёрнут — нажми на него).
Порядок важен: **сначала функция в облаке, потом навык** — навыку нужно выбрать готовую функцию.

### 1. Ключ связи
Включи в Homie «Принимать сообщения» — появится «Ключ связи».

### 2. Функция в Yandex Cloud
1. Открой [console.yandex.cloud](https://console.yandex.cloud/) → **Cloud Functions**.
   В первый раз облако попросит завести платёжный аккаунт — функции для навыков Алисы
   [не тарифицируются](https://yandex.ru/dev/dialogs/alice/doc/ru/deploy-ycloud-function).
2. **«Создать функцию»** → Имя: `homie` → «Создать».
3. Вкладка **«Редактор»** → среда **Python** (3.12 или новее) → «Продолжить».
4. В файле `index.py` удали пример и вставь код — кнопка **«Скопировать код навыка»** в Homie
   (или файл [`index.py`](index.py)). Точка входа: `index.handler`.
5. **Таймаут — 5 секунд** (по умолчанию 3 — мало). Память 128 МБ, сервисный аккаунт и сеть не нужны.
6. **«Переменные окружения»**: Ключ — `HOMIE_KEY`, Значение — «Ключ связи» (кнопка **«Скопировать»** в Homie).
7. **«Сохранить изменения»** внизу страницы.

### 3. Проверка функции (необязательно)
Вкладка **«Тестирование»** → вставь тестовый запрос (кнопка **«Скопировать тестовый запрос»** в Homie) →
«Запустить тест». Компьютер скажет «Тебе передали: привет от функции».

```json
{
  "version": "1.0",
  "session": { "new": true },
  "request": {
    "command": "передай привет от функции",
    "original_utterance": "передай привет от функции"
  }
}
```

### 4. Навык в Яндекс Диалогах
Открой [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) (тот же Яндекс ID, что на колонках) →
«Создать диалог» → «Навык». Обязательные поля:

| Поле | Что вписать |
|---|---|
| Название навыка | **минимум два слова**, например «Мой Хоуми» |
| Активационные имена | «+ Добавить» → «Хоуми» — по нему будешь звать навык; можно ещё «Хоми». Если одно слово не примет — зови по названию: «попроси мой Хоуми…» |
| Описание | любое, например «Передаёт сообщения на компьютер» |
| Backend | «Функция в Яндекс Облаке» → `homie` |
| Тип доступа | **Приватный** — модерация и тестирование не нужны |
| Категория | любая |
| Имя разработчика | любое |
| Иконка | кнопка **«Сохранить иконку»** в Homie (или [`icon.png`](icon.png)) |

Хранилище, сайт, AppMetrica и RTB не трогай. «Сохранить» → **«Опубликовать»**.

### 5. Готово
Скажи колонке: «Алиса, попроси Хоуми передать: привет».

## Как говорить

- «Алиса, попроси Хоуми передать на балкон: ужин готов»
- «Алиса, скажи Хоуми: иди есть»
- «Алиса, запусти Хоуми» → «Что передать на компьютер?» → «Иди есть»

## Если не работает

- **«Проверить» молчит** — нет интернета или выключено «Принимать сообщения».
- **Алиса отвечает «Навык не настроен»** — нет переменной `HOMIE_KEY` в функции.
- **Алиса говорит «Передала», а ПК молчит** — ключ в функции не совпадает с ключом в Homie
  (например, нажали «Новый ключ»). Скопируй ключ заново в `HOMIE_KEY`.
- Сообщения старше 2 минут (пока ПК спал) Homie не зачитывает.

Необязательно: переменная `SKILL_ID` (ID навыка из консоли Диалогов) — функция будет отвечать только ему.
